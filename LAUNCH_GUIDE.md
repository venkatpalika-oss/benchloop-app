# Bench & Loop — launch guide (no Mac needed)

This folder is a complete Capacitor app for Android and iOS. Codemagic, a cloud build service, compiles both versions on its own Android and Mac machines. You only need a web browser and, for uploading the project, the free GitHub Desktop app.

```
benchloop-app/
├── www/                  ← the app itself (HTML, CSS, JS, fonts). Edit here.
├── android/              ← native Android project (generated by Capacitor)
├── ios/                  ← native iOS project (generated by Capacitor)
├── assets/               ← icon and splash source images
├── docs/privacy.html     ← privacy policy page to host online
├── store-screenshots/    ← ready-made screenshots for both stores
├── codemagic.yaml        ← cloud build instructions
├── STORE_LISTING.md      ← text to paste into the stores
└── capacitor.config.json ← app name and ID
```

App ID / bundle ID: `com.benchloop.calculators`. This is permanent once you upload the first build. If you want a different one, change it **before step 4** (ask Claude to regenerate the project with your ID).

You also received `benchloop-android-signing-PRIVATE.zip`. It is the key that proves Android updates come from you. **Never put it in GitHub.** Back it up somewhere safe (password manager + cloud drive).

## 1. Create accounts (day 1)

| Account | Cost | Link |
|---|---|---|
| Google Play Console | $25 one-time | https://play.google.com/console/signup |
| Apple Developer Program | $99 per year | https://developer.apple.com/programs/enroll/ |
| GitHub | Free | https://github.com/signup |
| Codemagic | Free plan to start | https://codemagic.io/signup (sign up with GitHub) |

Apple enrollment requires an Apple ID with two-factor authentication and can take 1–2 days to approve. Start it first.

Google Play: a **personal** account must run a closed test with **12 testers for 14 days** before going public (step 4d). An **organization** account skips that but needs a D-U-N-S number. For a solo developer, personal is usually faster overall.

## 2. Put the project on GitHub

1. Install GitHub Desktop: https://desktop.github.com
2. Unzip `benchloop-app.zip`. In GitHub Desktop choose **File → Add local repository**, pick the `benchloop-app` folder, accept "create a repository", then **Publish repository**.
3. Privacy policy URL (both stores require one):
   - If the repository is **public**: on github.com open the repo → **Settings → Pages** → Source "Deploy from a branch", branch `main`, folder `/docs` → Save. Your URL becomes `https://<your-username>.github.io/benchloop-app/privacy.html`.
   - If you keep the repository **private**, GitHub Pages needs a paid plan. Instead, ask Claude to publish the privacy page as a public link.
   - Edit `docs/privacy.html` first to put in your support email.

## 3. Connect Codemagic

1. In Codemagic, **Add application** → GitHub → choose `benchloop-app` → project type **Other / codemagic.yaml**.
2. Open `codemagic.yaml` and change `you@example.com` to your email (two places). Commit and push in GitHub Desktop.

## 4. Android

**a. Upload your signing key.** Codemagic → **Team settings → Code signing identities → Android keystores → Add keystore**. Upload `benchloop-upload.jks` from the private zip, enter the password/alias from `KEYSTORE_DETAILS.txt`, and set the reference name to exactly `benchloop_keystore`.

**b. Build.** Codemagic → your app → **Start new build** → workflow **Android release**. After ~10 minutes you get:
- `app-release.aab` → for Google Play
- `app-release.apk` → download to your Android phone and install it to try the app right away (allow "install unknown apps" when asked).

**c. Create the app in Play Console.** Create app → name, default language, App, Free. Then complete everything under **Set up your app**: privacy policy URL, app access (no login), ads (no), content rating questionnaire, target audience (18+ or all ages), data safety (**no data collected**), app category (Tools), store listing (text in `STORE_LISTING.md`, icon = `assets/icon-only.png` resized to 512×512, screenshots from `store-screenshots/android-phone`, feature graphic 1024×500 — ask Claude to make one).

**d. Closed test (personal accounts).** Testing → **Closed testing** → create track → upload the `.aab` → add 12+ testers by email (a Google Group is easiest) → send them the opt-in link. Keep at least 12 opted in for 14 days in a row. Then **Apply for production** from the dashboard. Google reviews the application, then your production release.

**e. Optional, automatic uploads for future versions.** Follow https://docs.codemagic.io/yaml-publishing/google-play/ to create a Google Cloud service account JSON. In Codemagic → app → **Environment variables**, add `GCLOUD_SERVICE_ACCOUNT_CREDENTIALS` (paste the JSON, mark Secure) in a group named `google_play`. Then uncomment the two `google_play` blocks in `codemagic.yaml`.

## 5. iOS

**a. App Store Connect API key.** https://appstoreconnect.apple.com → **Users and Access → Integrations → App Store Connect API** → generate a key with **App Manager** access → download the `.p8` (you can only download it once) and note the Issuer ID and Key ID.

**b. Add it to Codemagic.** Team settings → **Team integrations → Developer Portal → Manage keys → Add key**. Name it exactly `BenchLoop ASC key` and upload the `.p8` with the IDs.

**c. Register the app.**
1. https://developer.apple.com/account/resources/identifiers → **+** → App IDs → App → Bundle ID (explicit) `com.benchloop.calculators`, description "Bench and Loop".
2. App Store Connect → **Apps → +  → New App** → iOS, name "Bench & Loop", pick that bundle ID, SKU `benchloop-001`.
3. Open the new app → **App Information** → copy the numeric **Apple ID** (e.g. 6740012345) into `codemagic.yaml` as `APP_STORE_APPLE_ID`. Commit and push.

**d. Signing certificate and profile.** Codemagic → Team settings → **Code signing identities**:
- **iOS certificates → Generate certificate** → type Apple Distribution, using the key from 5b. Download the certificate and its password when shown and keep them with your Android key.
- **iOS provisioning profiles → Fetch profiles** → select the App Store profile for `com.benchloop.calculators`. If none is listed, create one at https://developer.apple.com/account/resources/profiles (Distribution → App Store Connect → your bundle ID → the certificate from above), then fetch again.

**e. Build.** Start a build with workflow **iOS release**. It builds on Codemagic's Mac and uploads to **TestFlight** automatically (Apple processes it in 10–30 minutes). If you have an iPhone, install the TestFlight app to try it.

**f. Submit.** In App Store Connect fill in the listing from `STORE_LISTING.md`, screenshots from `store-screenshots/iphone-6.9`, privacy policy URL, **App Privacy → Data Not Collected**, age rating 4+, price Free. Choose the TestFlight build, then **Add for Review → Submit**.

## 6. Releasing updates

1. Edit files in `www/` (or ask Claude for changes).
2. Raise the version: `versionName` in `android/app/build.gradle` and `MARKETING_VERSION` in `ios/App/App.xcodeproj/project.pbxproj` (e.g. 1.0.0 → 1.1.0). Build numbers increase automatically.
3. Commit and push in GitHub Desktop, then start both Codemagic workflows.

## Common rejection reasons to avoid

- Missing or broken privacy policy link.
- Data safety / App Privacy answers that don't match the app (this app collects nothing; answer that way).
- Placeholder text left in listings — search for `[` and `example.com` before submitting.
- Apple guideline 4.2 (minimum functionality): if a reviewer says the app is "a repackaged website", reply that it is a fully offline native app with 16 calculators, favourites, saved inputs and haptics. Adding a feature such as a saved calibration log strengthens this.

## Working on your own computer (optional)

With Node.js installed: `npm install`, then open `www/index.html` in a browser to test changes. After editing, `npx cap sync` copies the web files into the native projects. Android Studio (Windows/Mac/Linux) can run the Android version on an emulator; the iOS version needs a Mac or Codemagic.
